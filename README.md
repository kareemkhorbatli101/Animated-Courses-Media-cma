# Figures - CMA Part 1, Books 1 to 4

The author's own figures for the four volumes at
<https://learnactively.com/cma/>. Extracted from the source books by
`tools/cma_book` and published here by `tools/cma_media.py`; nothing here
is drawn or edited by hand.

They live apart from the site so that the site's repository carries only
text. The volumes fetch them from this repository's own GitHub Pages site.
All four volumes share one flat folder because the author's numbering is
unique across them (F01-, F201-, F301-, F401-); the publisher refuses to
run if that ever stops being true.

`tools/cma_media_ref.json` in the course pipeline records a sha256 for every
file, so a figure that changes under the same name is visible rather than
silent.
